What is Root? What is IAM? What is Shared Responbility Model? 

The shared responsibility  model is the security practices that assigns responsibility to both the cloud provider, and the customer. This means AWS will be responsible for protecting the infrastructure, while the customer will be responsible for protecting their deployment of said infrastructure (IaaS). Root is the highest privilege for an account or access. It's a general term for a lot of applications, but in terms of AWS, it's the parent account that has access to everything. IAM is the practice of configuring permissions for users and groups. And specifically, securing those permissions so security can be maintained.
